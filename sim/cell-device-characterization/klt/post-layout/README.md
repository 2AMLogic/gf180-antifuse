Paired schematic-vs-extracted re-run of the access-device bench (I_off, R_on)
on `klt pex` extractions of the three drawn bitcells.  This directory is the
probe's bench half; the extraction half lives under `layout/<cell>/pex/`.
Ungraded supporting evidence only -- `7.analog` is NOT cited from this probe
(array-level post-layout verification stays with the array layout; see
`signoff/README.md`).

- **Run**: `runs/20261121-073730-17c2f21/` (this README is rendered by the latest ingest)
- **Timestamp**: 2026-11-23T15:35:34Z
- **Requests**: `requests/c<N>_{schematic,extracted}/{body.spice,ioff.json,ron.json}`,
  generated by `mk_post_layout_requests.py`; corner/measurement builders reused
  verbatim from `../mk_klt_requests.py`, axes cut to the bound corner:
  I_off at `ff / 125 degC / vbl = 1.1 V` over the three OFF-gate biases;
  R_on at `ss / -40 degC / vbl = 0.9 V` at the candidate's on-gate bias, 10 MHz.
- **Legs**: schematic = the cell's fixed-geometry `lvs_reference.spice` (the same
  netlist `klt pex --reference-netlist` used; drawn geometry, no sizing overrides);
  extracted = `layout/<cell>/pex/extracted.spice` included verbatim, instantiated in
  the emitted `.SUBCKT` pin order (see each `requests/c<N>/provenance.json` for the
  ordered pin map and both DUT sha256s).  Supplies, body connection, model sections,
  solver settings and measurements are identical on both legs; `netlist_source` is
  `schematic` / `extracted`.
- **Extraction**: klayout-tools `0.9.2` (KLayout `0.30.13`), `--deck gf180mcu --pdk
  gf180mcuD --extract-only`; `body_bias.status: "biased"` for all three cells
  (full blocks quoted in each `layout/<cell>/pex/README.md`).
- **Fleet**: `klt sim --backend batch --wait-for-capacity 600`; runner klt `0.9.0`,
  client `0.9.2` (`runner_compatibility: match` on every job; job ids per row below).
- **Known representation divergence**: every drawn MOS capacitor extracts as a
  linear `C` card (deck area law), not the PDK's nonlinear `cap_*` subcircuit --
  `model_mismatch` reports the cap in `reference_only` for all three cells
  (2AMLogic/klayout-tools#7004).  I_off is a DC measurement (cap open on both
  legs); R_on at 10 MHz sees the linearised cap on the extracted leg only.
- **gmin floor**: both legs keep `.options gmin=1e-13`; I_off remains a

## Dispositions

- All three extractions are usable: access-device model, geometry and drain
  orientation match the per-cell LVS reference (evidence quoted per cell in
  `layout/<cell>/pex/README.md`); `body_bias.status` is `biased` everywhere;
  parasitics present (per-net lumped R + substrate C, plus C2's coupling caps).
- No refusal occurred, so no upstream refusal link was needed; the MOS-cap
  linearisation finding is linked on 2AMLogic/klayout-tools#7004 (the runset-route
  issues #6559/#6606 cover families the curated deck cannot recognise at all --
  not this case: all device families here bind under the curated deck with `--pdk`).
- **C3 R_on difference: measured, cause open.** The fleet summary gives a large
  negative C3 R_on difference.  A local single-component control (committed C3
  DUTs, same PDK sections and source biases, `Re(-V(BL)/I(VBL))` at ss, -40 degC,
  10 MHz, libngspice 42; the fleet ran ngspice 47) swapped only the capacitor card
  within each row:

  | C3 circuit | PDK MOS capacitor | Linear 1.232 fF capacitor |
  |---|---:|---:|
  | Schematic | 2912.900 ohm | 2912.905 ohm |
  | Extracted | 118.822 ohm | 168.011 ohm |

  The large schematic-vs-extracted difference persists with the same capacitor
  representation on both legs, so it is not attributed to the capacitor model;
  no controlled comparison has yet established the cause.
- Numbers above cover exactly the drawn Minimum x Minimum split of each
  candidate's GDS (one cell per candidate; no other splits, no averaging).

## C3 R_on divergence diagnosis (issue #481)

Characterization only: no graded row, no `7.analog` citation, no geometry or PDK
change. Region III (C3, drawn Minimum x Minimum) only; C1/C2 were not re-run and
nothing is averaged. Harness: `diagnosis/run_c3_diagnosis.py` (one local
`ngspice -b` per variant, ngspice 47, same PDK sections / biases / 10 MHz
`Re(-V(BL)/I(VBL))` as `requests/c3_*/ron.json`); raw results are append-only in
`diagnosis/results/`.

**Baseline sanity (ss / -40 degC / vbl 0.9 V, vwl 0):** schematic 2903.5 ohm,
extracted 168.0 ohm -- reproduces the fleet numbers before any perturbation.

| variant (ss / -40 degC / vbl 0.9 V) | R_on (ohm) |
|---|---:|
| schematic baseline | 2903.5 |
| schematic, pfet D/S swapped | 2902.9 |
| extracted baseline | 168.0 |
| extracted, pfet D/S swapped | 166.3 |
| extracted, all substrate C removed | 282.4 |
| extracted, each lumped R shorted (storage / BL / PL / VB / WL) | 162.9 - 167.9 |
| extracted, pfet `AS/AD/PS/PD` removed | 975.9 |
| extracted, parasitics removed **and** `AS/AD/PS/PD` removed | 2938.2 |
| schematic, `AS=AD=0.21p PS=PD=1.84u` added | 274.5 |
| schematic, linear 1.232 fF cap, no junction geometry | 2912.9 |
| schematic, linear 1.232 fF cap **plus** junction geometry | 275.4 |

Confirmation at a second corner (ff / 125 degC / vbl 1.1 V; the channel is far
less conductive so absolute values are MOhm): schematic linear-cap 9.579e6 vs
extracted cap-only without junction geometry 9.579e6; schematic linear-cap plus
junction geometry 6.763e6 vs extracted cap-only 6.763e6 (equal to all printed digits).

**Hypotheses**
- *pfet S/D/body orientation (vs `lvs_reference.spice`)*: **refuted.** The extracted
  card's order is D=storage, G=WL, S=BL, B=VB, identical to the reference; swapping
  D/S on either leg moves R_on by <1.2%.
- *Extracted per-net R / substrate C shunting the 10 MHz path*: **refuted as the
  cause.** Removing every parasitic R and C changes the extracted leg 168 -> 282
  ohm (1.7x), nowhere near the 17x gap; each lumped R moves it by <=3%.
- *Not in the issue's list, measured:* the extracted pfet card carries explicit
  junction geometry (`AS=AD=0.21P PS=PD=1.84U`); the LVS reference card carries
  none, so the schematic leg has no S/D junction capacitance to the AC-grounded
  body (VB). Adding that geometry to the schematic leg drops it 2903.5 -> 274.5
  ohm; removing it from the extracted leg (with parasitics also removed) lifts it
  168 -> 2938 ohm. With capacitor model, parasitics and junction geometry equalised
  the legs agree to 2.5% (ss) / exactly (ff). **Confirmed: this accounts for
  essentially the whole gap.**

**Cause: correct parasitic result** -- the extracted leg models real S/D junction
area/perimeter that the schematic reference omits. It is not an extracted-netlist
terminal defect and not an upstream extractor defect, so no `2AMLogic/klayout-tools`
issue is filed. The quantity is Re(Z) of a ~1e7-1e8 ohm capacitive reactance, so it
is highly sensitive to any small shunt capacitance; the schematic-leg R_on is a
junction-geometry-free number and is not comparable to the extracted one without
adding the geometry. C1/C2 extracted cards also carry `AS/AD/PS/PD`; why their
R_on is insensitive was not investigated (out of scope). The `signoff/README.md`
`model_mismatch` disposition text is unchanged.
