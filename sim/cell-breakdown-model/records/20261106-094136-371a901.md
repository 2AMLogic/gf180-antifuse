- **Method**:
  - `I_off` = max over {unprogrammed, programmed(median filament)} cells x 3 OFF levels x 4 sub-configs of the BL current with WL at an OFF level and PL = 0. The programmed-OFF case is the worst sneak case (CN pulled to PL, full V_DS across the OFF device) and is new relative to #62's unprogrammed-only `I_off`.
  - `I_sneak_max` = (N-1) x `I_off`, N = 32 (`spec/split-axis-plan.md`). Currents below abstol (1e-12 A) are not resolved by ngspice, and `gmin` = 1e-13 S dominates them; the **solver-floor-limited bound** `I_sneak,f` = (N-1) x max(`I_off`, abstol) is therefore the number the verdict uses. Model leakage below abstol is UNRESOLVED: the raw values are exactly 0.0 A or +-k x 2^-54 (machine-epsilon residue of both signs), i.e. solver roundoff, not model output, and `abs()` in the derivation hides the sign. The bound is a resolution floor, not a bound on physical leakage and not a prediction.
  - `I_zero,f` = `I_sneak,f` + max(selected-unprogrammed current, abstol): the current an UNPROGRAMMED selected cell reads together with the N-1 unselected cells. `I_prog` = worst-filament (rf_wc) programmed read current, minimum over sub-configs. A bias is **feasible** iff, with no failed corner, min over all corners of `I_prog` > max over all corners of `I_zero,f` (a single common `I_ref` exists; the window is the ratio). The per-corner pass count (same-corner comparison) is also given.
