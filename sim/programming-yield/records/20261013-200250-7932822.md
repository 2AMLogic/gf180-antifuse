- **Success criterion** (per sample; a sample is exactly one of ok / fail / inconclusive):
  1. the breakdown state is **latched** at the end of the transient: `st >= 0.99` (`st <= 0.01` is *not programmed* = fail; anything in between is a half-formed filament and is **inconclusive**, not counted either way);
  2. the **peak access-path current** during the pulse, max |i(VBL)|, is `<= 1.0000e-03 A`. This bound is an **ASSUMED campaign parameter, not a ratified one**: `spec/architecture.md` section 2 leaves `I_target_max` open and the cell model has no ballast resistor, so the current limit here is the access device alone. The peak-current distribution is tabulated so any other bound can be applied to the saved data;
  3. **read decision: NOT EVALUATED for Candidate 3.** The #62 records show no `I_ref` window at the inherited placeholder read bias (I_prog_min below I_sneak_max; follow-up #75), so "post-pulse read decision correct" has no defined threshold. The Candidate 3 yields below are therefore **upper bounds** on a full read-decision yield (latch and current bound only).

- **Sample sizing**: n = 100 Monte Carlo samples per (sub-configuration, pulse condition, PVT corner) cell. The 95 % Wilson interval half-width is at most 0.098 (p = 0.5, n = 100) and narrower toward the ends; pooling the 3 x 3 PVT corners of a condition multiplies the sample by up to 9. Chosen from that half-width, not from a yield target. A cell that needs a tighter interval is re-run with a larger n as a new record.
- **Sampler**: `klt sim` `monte_carlo` {n=100, seed=20261013, vary="mismatch"}; the draws are `ubd = aunif(0.5, 0.5)` clamped to [1e-06, 1 - 1e-06] (uniform Weibull quantile) and `zrf = agauss(0, 1, 1)` (standard-normal filament draw), evaluated once per run from the `.options seed=` klt writes. Seeds derive from (seed, corner index, sample index): corners within a request are independent samples, while the same corner index in another request (the other access sizing, or another pulse width) reuses the same draws -- a paired design, README "Draw reuse".

- **Corner matrix run**: ['moscap_ff', 'moscap_ss', 'moscap_typical'] x temperatures [-40, 27, 125] degC x pulse conditions below x access sizing min, 2x (capacitor geometry fixed at `min`). Programming transient only; the read-side PVT is the table below.

The model must gain area scaling (Poisson-area Weibull) before that split axis can be read from a yield curve; running it now would manufacture a null result.
